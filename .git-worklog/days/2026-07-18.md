## 主要異動

### 共享一個差異解析器，刪除 worktree.py 中的重複程式碼

- **異動內容：** `worktree.py` 和 `history.py` 各自實作了 `_git`、`_git_ok`、`_parse_raw`、`_parse_numstat` 和 `GitError`，這種重複是因為它們曾是獨立指令碼。現在都在套件內並一起發布，所以 `worktree.py` 改為從 `history.py` 匯入這些函式。
- **程式碼行為：** `worktree.py` 不再複製 git 輔助程式和差異解析器，改為匯入它們。`GitError` 現在只有一個類別，使得工作樹 git 失敗會透過相同的 CLI catch 塊回報為 `GIT_ERROR`，而不是 `UNEXPECTED_ERROR`。
- **實作方式：** 移除 `worktree.py` 中的 `_git`、`_git_ok`、`_parse_raw`、`_parse_numstat` 函式以及 `GitError` 類別，改為新增 `from git_worklog.analysis.history import GitError, _git, _git_ok, _parse_numstat, _parse_raw`。修改 `_diff_files` 以使用匯入的解析器。history 的 `_parse_raw` 回傳更完整的項目（含舊/新 mode 與 sha，用於偵測 submodule 和 mode 變化），`_diff_files` 只讀取它需要的子集，所以此模組的輸出保持不變。
- **影響範圍：** 減少程式碼重複，降低維護負擔。縮小工作樹分析模組的大小。改善 git 錯誤的一致性處理。
- **相關檔案：** `git-worklog/git_worklog/analysis/worktree.py`、`CHANGELOG.md`
- **相關 commits：** d6f6687 (Daniel Hsieh) refactor(analysis): share one diff parser between history and worktree；f00b9f3 (Daniel Hsieh) Merge pull request #30 from g761007/refactor/dedupe-diff-parser
- **測試與驗證：** `tests/test_git_collection.py` — 二進位檔、rename/copy、submodule、merge 偵測等情況
- **維護注意事項：** Git 輔助程式現在是單一複本，任何未來的修改應在 `history.py` 進行

### 提取共用的原子寫入函式，取代三個重複的實作

- **異動內容：** mkstemp → write → fsync → validate → `os.replace` 的序列在 `writer.py` 和 `migrate.py` 中各實作一次。`migrate.py` 原本是獨立指令碼，現在已在套件中；`writer.py` 的 `apply_index` 和 `migrate.py` 的 `_atomic_write` 是相同邏輯的兩個副本。提取為 `atomic_write(target, content, validate, *, prefix)`，由兩個原始位置呼叫。
- **程式碼行為：** `migrate.py` 改為呼叫 `atomic_write` 而不是實作自己的 `_atomic_write`。`writer.py` 的 `apply_index` 成為 `atomic_write` 的簡潔包裝器。`apply_days` 保持獨立，因為它的多檔案事務處理需要不同的演算法。
- **實作方式：** 在 `writer.py` 中建立 `atomic_write` 函式，接受 target、content、validate 函式以及 prefix 參數。`migrate.py` 移除 `_atomic_write` 並改為 `from git_worklog import writer`，呼叫時傳入 `.rw-mig-` 前綴。`apply_index` 改為一行呼叫。
- **影響範圍：** 刪除重複的寫入邏輯，集中在一個位置。Prefix 保留為參數以便區分不同寫入器留下的孤立臨時檔案。
- **相關檔案：** `git-worklog/git_worklog/writer.py`、`git-worklog/git_worklog/migrate.py`、`CHANGELOG.md`
- **相關 commits：** fc845f7 (Daniel Hsieh) refactor(writer): one atomic single-file write, not three
- **測試與驗證：** `tests/test_migrate.py` — migrate 的原子寫入行為；`tests/test_worklog_engine.py` — `apply_index` 與 writer 行為
- **維護注意事項：** 任何對原子寫入邏輯的變更應在 `atomic_write` 進行；prefix 參數用於區分墜毀後遺留的孤立檔案，勿移除或統一
